# Curso Completo de Desenvolvedor Node.js e MongoDB

Este repositório contém os projetos, exercícios e exemplos desenvolvidos durante o **Curso Completo de Desenvolvedor Node.js e MongoDB**.

O objetivo deste repositório é **registrar a evolução do aprendizado**, aplicar conceitos na prática e servir como material de consulta futura.

---

## 📚 Conteúdo do Curso

Ao longo do curso, são abordados os seguintes tópicos:

- Fundamentos do **Node.js**
- Módulos e gerenciamento de pacotes com **npm**
- Criação de servidores com **Express**
- Rotas, middlewares e controllers
- Integração com banco de dados **MongoDB**
- Utilização do **Mongoose**
- CRUD completo (Create, Read, Update, Delete)
- Organização de projetos em MVC
- Variáveis de ambiente com **dotenv**
- Boas práticas de desenvolvimento backend
- Tratamento de erros
- Introdução à criação de APIs RESTful

---

## 🛠️ Tecnologias Utilizadas

- Node.js  
- Express.js  
- MongoDB  
- Mongoose  
- JavaScript (ES6+)  
- npm

Consolidar conhecimentos em backend com Node.js e MongoDB, evoluindo do nível iniciante ao intermediário, com foco em aplicações reais.
